# AI Team Hub · AI 模型运营工作台

这是 AI 多模型管理产品的前端 MVP。双击 index.html 即可打开，也可以用任意静态文件服务器运行。

## 这版已经能演示什么

- 运营总览：调用量、Token、费用、模型健康状态和调用趋势
- AI 工作台：任务模板、模型选择、模拟回答和故障切换
- 管理员/普通用户视角：普通用户只能看到自己的工作入口和记录
- 模型管理：主模型、备用模型、状态和调用量
- 用户与额度：成员额度、使用进度和可用模型
- 成本分析：模型费用分布和成本优化建议
- 调用记录：按用户/摘要搜索、按模型筛选、导出 CSV
- 故障日志：失败、重试和自动切换事件
- 任务模板：使用、编辑描述和新建模板

## 当前限制

页面仍处于演示模式：模型回答、费用、Token、用户、权限和日志都是前端内存中的模拟数据，刷新页面会恢复初始数据。没有真实登录、数据库、API 调用、支付或服务端鉴权。

## 下一步接入点

1. 服务端保存模型配置和 API 密钥引用，前端永远不直接暴露密钥。
2. 接入一个真实模型 API，先跑通请求、错误处理和 Token 记录。
3. 用数据库保存用户、额度、调用记录和审计日志。
4. 增加服务端鉴权，让管理员和普通用户权限真正生效。
5. 用真实价格表替换演示费用，补充限流、预算告警和数据导出。

请勿把 API 密钥、个人数据或客户数据提交到 GitHub。
